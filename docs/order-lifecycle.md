# Закрытие и отмена заказов (1С)

Справочники **не являются перечислениями**: записи статусов хранятся в информационной базе.
Добавить **в режиме 1С:Предприятие** (после загрузки конфигурации):

| Справочник | Наименование | КодСтатуса |
| --- | --- | --- |
| СтатусыЗаказов | Закрыт | `closed` |
| СтатусыЗаказов | Отменён | `cancelled` |
| СтатусыРабот | Автомобиль выдан владельцу | `vehicle_handed_over` |

Существующие `under_review`, `in_progress`, `completed` и `refused` не удалять.
У новых статусов заказа **снять флаг «Начальный»**; для `closed` можно
установить «Требует оплаты». Убедитесь, что в «Статусы оплаты» существует
**`paid`** (оплата подтверждена). Пока эквайринг не подключён, это ручное
подтверждение менеджера, не доказательство банковского платежа.

## Правила

- **На рассмотрении** → **В работе** → **Завершён** → **Закрыт**.
- При завершении работ `completed` означает готовность автомобиля к выдаче,
  но **не** факт выдачи. Подходящий рабочий статус ожидания: `owner_visit`.
- **Закрытие**: в форме документа 1С указать статус работ
  `vehicle_handed_over`, статус оплаты `paid`, статус заказа `closed`
  и сохранить. Предыдущий сохранённый статус заказа обязан быть `completed`.
  `ДатаЗакрытия` проставляется серверным кодом при сохранении.
  Через HTTP API `closed` запрещён (403): на фронтенде кнопки закрытия нет.
- **Отмена**: из `under_review` или `in_progress`, требуется
  `ПричинаОтказа`. Статус работ автоматически станет `refused`.
  `completed` **с непустой причиной отказа** в старых клиентах
  автоматически преобразуется HTTP-сервисом в `cancelled`.
- **Закрытые и отменённые** документы нельзя изменять обычной записью.
  Перед закрытием нужно окончательно согласовать стоимость работ.
- Отмена не входит в статистику выполненных работ; `completed` и
  `closed` вместе считаются выполненными. Старые отказы
  (`completed` с `ПричинаОтказа`) не засчитываются в выполненные.

## Ограничения и проверка

- Создание трёх **элементов справочников** выполняется вручную в БД;
  изменения метаданных сами по себе их не создают.
- `ДатаЗакрытия` — **новый реквизит документа**. Для ручной работы его
  рекомендуется сделать доступным только для просмотра на форме 1С.
- Доступ к HTTP API 1С по-прежнему должен быть закрыт от интернета:
  `actorId/actorRole` в параметрах **не заменяют** серверную аутентификацию.
- Перед применением обязательно проверить конфигурацию в Конфигураторе
  и протестировать жизненный цикл на тестовой копии базы, включая отмены,
  повторное сохранение и расчёт статистики.
- Участие специалистов фиксируется по истории назначений; ранее удалённые
  до внедрения истории назначения не восстанавливаются.
