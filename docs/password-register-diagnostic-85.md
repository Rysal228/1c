# Диагностика ошибки параметра № 2 при чтении хеша из регистра 1С 8.5.1

Исходный опыт: вызов двух встроенных методов для хеша **в памяти** успешен
(`PASS. Тип значения: Строка`), но после сохранения значения в
`ПаролиПользователейПриложения.СохраняемоеЗначение` и повторного чтения
`ПроверитьСоответствиеПароляПользователяСохраняемомуЗначению` сообщает
`Недопустимое значение параметра номер 2`.

Это не доказывает причину. Диагностика ниже проверяет **строгое**
соответствие исходной и прочитанной строк, типы, длины и ограничение 1024
символов. Никакие пароли, хеши и их префиксы не выводятся.

Тест выполняется **только в тестовой копии информационной базы**.
Внешняя обработка с управляемой формой: код вставить в модуль формы,
как в предыдущем тесте. При открытии запустится автоматически.
Создаётся искусственный пользователь и запись регистра, затем
транзакция **обязательно откатывается**; после проверки дополнительно
убедиться в отсутствии тестового пользователя по телефону.

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
    Сообщить(ПроверитьХранениеПароляНаСервере());
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПроверитьХранениеПароляНаСервере()

    Телефон = "79990000901";
    Пароль = "OneC-Register-Test-Only!2026";

    Если НЕ Справочники.ПользователиПриложения.НайтиПоРеквизиту(
        "Телефон", Телефон).Пустая() Тогда
        Возврат "SKIP: тестовый номер телефона уже используется.";
    КонецЕсли;

    Диагностика = "до сравнения";
    НачатьТранзакцию();
    Попытка
        Пользователь = Справочники.ПользователиПриложения.СоздатьЭлемент();
        Пользователь.Телефон = Телефон;
        Пользователь.Имя = "Тест";
        Пользователь.Активен = Истина;
        Пользователь.Записать();
        Ссылка = Пользователь.Ссылка;

        Хеш = ВычислитьСохраняемоеЗначениеПароляПользователя(Пароль);
        Если НЕ ПроверитьСоответствиеПароляПользователяСохраняемомуЗначению(
            Пароль, Хеш) Тогда
            ВызватьИсключение "Проверка хеша в памяти не прошла.";
        КонецЕсли;

        Набор = РегистрыСведений.ПаролиПользователейПриложения.СоздатьНаборЗаписей();
        Набор.Отбор.Пользователь.Установить(Ссылка);
        Набор.Прочитать();
        Набор.Очистить();
        Запись = Набор.Добавить();
        Запись.Пользователь = Ссылка;
        Запись.СохраняемоеЗначение = Хеш;
        Набор.Записать();

        Проверка = РегистрыСведений.ПаролиПользователейПриложения.СоздатьНаборЗаписей();
        Проверка.Отбор.Пользователь.Установить(Ссылка);
        Проверка.Прочитать();

        Если Проверка.Количество() <> 1 Тогда
            ВызватьИсключение "Ожидалась ровно одна запись регистра.";
        КонецЕсли;

        Для Каждого СтрокаРегистра Из Проверка Цикл
            Прочитанное = СтрокаРегистра.СохраняемоеЗначение;
            ТипИсходного = Строка(ТипЗнч(Хеш));
            ТипПрочитанного = Строка(ТипЗнч(Прочитанное));
            ДлинаИсходного = СтрДлина(Хеш);
            ДлинаПрочитанного = СтрДлина(Прочитанное);
            Равны = (Хеш = Прочитанное);

            Диагностика = "тип исходного=" + ТипИсходного
                + "; тип прочитанного=" + ТипПрочитанного
                + "; длина исходного=" + Строка(ДлинаИсходного)
                + "; длина прочитанного=" + Строка(ДлинаПрочитанного)
                + "; совпадают=" + Строка(Равны);

            Если НЕ Равны Тогда
                ОтменитьТранзакцию();
                Возврат "DIAG: " + Диагностика
                    + "; проверка прочитанного хеша пропущена; откат выполнен.";
            КонецЕсли;

            Если НЕ ПроверитьСоответствиеПароляПользователяСохраняемомуЗначению(
                Пароль, Прочитанное) Тогда
                ВызватьИсключение "Прочитанный хеш отклоняет правильный пароль.";
            КонецЕсли;
        КонецЦикла;

        ОтменитьТранзакцию();
        Возврат "PASS: сохранённый хеш принят; " + Диагностика
            + "; откат выполнен.";

    Исключение
        Текст = ОписаниеОшибки();
        ОтменитьТранзакцию();
        Возврат "FAIL: " + Текст + "; " + Диагностика
            + "; откат выполнен.";
    КонецПопытки;

КонецФункции
```

### Как интерпретировать

- `совпадают=Ложь`: сохранённая строка изменилась. Если исходная длина
  превышает 1024, ресурс слишком короткий; если нет — проверить
  фактические свойства ресурса, преобразование типа, кодировку,
  режим пароля и платформенную обработку содержимого. Ничего не
  менять наугад до результата.
- `совпадают=Истина` и ошибка параметра 2: проблема не в явном
  несовпадении строк, дальше исследовать ограничения самой
  платформенной функции при хранении/извлечении.
- `PASS`: прежнюю ошибку следует воспроизвести и сравнить условия
  запуска (БД, конфигурация, права, метаданные).
- Длины и булево совпадение безопасно сообщать без текста значений.

Никогда не печатать хеш, даже его префикс. Пока тест не проходит,
**не** устанавливать реальные пользовательские пароли, не включать
новый вход Django, не менять MAX и JWT.
