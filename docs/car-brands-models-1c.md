# Марки и модели автомобилей в 1С

## Объекты

- `Справочник.МаркиАвтомобилей`: наименование, автоматически назначаемый код, нативный UUID ссылки 1С.
- `Справочник.МоделиАвтомобилей`: наименование, код, обязательная ссылка `Марка` на `Справочник.МаркиАвтомобилей`.
- В клиенте **1С:Предприятие** открывайте раздел **Автосервис** → **Марки автомобилей** / **Модели автомобилей**. Для каждого справочника используется стандартная форма списка, для создания и редактирования — собственная управляемая **ФормаЭлемента**.
- В форме модели доступны поля «Марка» и «Наименование». Марку можно выбрать из списка ранее созданных марок.

## Правила записи

- Запрещены пустые наименования.
- Наименование очищается от пробелов по краям.
- Две марки с одинаковыми названиями (без учёта регистра) не допускаются.
- Две модели с одинаковыми названиями **внутри одной марки** не допускаются; для разных марок такое название разрешено.
- Нельзя сохранить модель без выбранной марки.
- Код назначает сама платформа 1С (`Autonumbering=true`).

## Проверка в Конфигураторе

1. Загрузите **XML-файлы конфигурации из ветки/PR**, а не старый `1Cv8.cf`. Метаданные соответствуют формату `2.21` (1С 8.5.1).
2. Проверьте конфигурацию, обновите конфигурацию базы данных и запустите **1С:Предприятие**.
3. В разделе «Автосервис» создайте марку «Toyota», затем модель «Camry» с маркой Toyota.
4. Убедитесь, что вторую «toyota» или «Camry» в Toyota создать нельзя, а «Camry» в другой марке — можно.
5. Проверьте выбор марки из формы модели, редактирование ранее созданного элемента и списки.

## Что НЕ менялось

- Справочник пользователей, их роли, MAX, пароли и HTTP-сервисы.
- Django/PostgreSQL, Angular и синхронизация справочников с сайтом. **Сейчас это только каталог 1С.**
- Файл `1Cv8.cf` в репозитории: его необходимо пересобрать и залить после проверки в вашей базе.
