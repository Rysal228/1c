# Первоначальная установка пароля приложения внутри 1С (без HTTP)

## Для чего это нужно

В 1С 8.5.1.1522 проверено:
- встроенные функции вычисления/проверки сохраняемого значения пароля;
- сохранение в регистр `ПаролиПользователейПриложения` с ресурсом
  `СохраняемоеЗначение: Строка(1024)`;
- хеш 224 символа сохранился и прочитался без потерь;
- тестовая транзакция отменена.

Этот документ описывает **одноразовую локальную внешнюю обработку** для
**первоначальной установки** нового пароля *существующему* пользователю
справочника `ПользователиПриложения`. Это **не HTTP-сервис**,
не установка пароля системному пользователю информационной базы 1С,
не перенос прежнего хеша Django и не механизм самостоятельного сброса.

**Пока не использовать для трёх реальных пользователей**: Django ещё
проверяет их старые пароли локально; перед живым включением необходимо
согласовать и проверить смену логина/выдачи JWT. MAX не менять.

### Модель доступа / важное ограничение

В этой базе пока **нет системных пользователей ИБ**, поэтому у платформы
не настроено разграничение администраторов и обычных пользователей
по ролям 1С. Код ниже **не способен проверить, кто именно нажал кнопку**.
Нельзя называть его защищённой административной формой для общего
доступа. Использовать только в контролируемом локальном сеансе
доверенного оператора, держать `.epf` вне публичных каталогов,
не включать в общие команды конфигурации и не раздавать его другим.
Если в 1С есть другие операторы с прямым доступом, необходимо сначала
организовать безопасное администрирование и права, а не применять
обработку к реальным пользователям.

## Создание обработки (для проверки формы, без реальных паролей)

1. Конфигуратор → **Файл → Новый → Внешняя обработка**.
2. Имя: `УстановкаПароляПриложения`.
3. **Формы** → Добавить → управляемая форма, основная форма обработки.
4. Во вкладке **Реквизиты** самой формы создать:
   - `Пользователь`, тип **СправочникСсылка.ПользователиПриложения**;
   - `НовыйПароль`, тип **Строка**, длина **128**, переменная;
   - `ПовторПароля`, тип **Строка**, длина **128**, переменная.
5. Во вкладке **Элементы** добавить поле ввода для каждого
   реквизита. Для полей `НовыйПароль` и `ПовторПароля`
   в **свойствах самих элементов** выставить
   **Режим пароля = Да**, чтобы введённые символы были замаскированы.
   Не выводить введённое значение в надписях или подсказках.
6. Во вкладке **Команды** создать команду
   `УстановитьНачальныйПароль` с обработчиком с тем же именем.
   Разместить кнопку этой команды на форме.
7. В **модуль формы** вставить код ниже.
   Обработчик `ПриОткрытии` не нужен.
8. Сохранить как `УстановкаПароляПриложения.epf`.
   Не публиковать внешнюю обработку как веб-сервис и не включать
   в общую пользовательскую навигацию 1С.

## Код модуля формы

```bsl
&НаКлиенте
Процедура УстановитьНачальныйПароль(Команда)

    // Не отправляем пароль на HTTP-сервер и не выводим его в сообщения.
    // Очистка полей выполняется как после успеха, так и после ошибки.
    Попытка
        Если НовыйПароль <> ПовторПароля Тогда
            Сообщить("Пароли в двух полях не совпадают.");
        Иначе
            УстановитьНачальныйПарольНаСервере(Пользователь, НовыйПароль);
            Сообщить("Первоначальный пароль установлен в 1С.");
        КонецЕсли;
    Исключение
        // Исключения платформы не публикуем вместе с введённым паролем.
        Сообщить("Не удалось установить пароль. Проверьте пользователя,"
            + " длину пароля и отсутствие уже установленного пароля.");
    КонецПопытки;

    НовыйПароль = "";
    ПовторПароля = "";

КонецПроцедуры


&НаСервереБезКонтекста
Процедура УстановитьНачальныйПарольНаСервере(СсылкаПользователя, Пароль)

    Если ТипЗнч(СсылкаПользователя)
        <> Тип("СправочникСсылка.ПользователиПриложения")
        Или СсылкаПользователя.Пустая() Тогда
        ВызватьИсключение "Не выбран пользователь приложения.";
    КонецЕсли;

    Если ТипЗнч(Пароль) <> Тип("Строка")
        Или СтрДлина(Пароль) < 12
        Или СтрДлина(Пароль) > 128 Тогда
        ВызватьИсключение "Длина пароля должна быть от 12 до 128 символов.";
    КонецЕсли;

    // При отсутствии системных пользователей ИБ это не проверка прав.
    // Запускать только в контролируемом доверенном сеансе 1С.
    НачатьТранзакцию();
    Попытка
        Пользователь = СсылкаПользователя.ПолучитьОбъект();
        Если Пользователь = Неопределено Тогда
            ВызватьИсключение "Пользователь не найден.";
        КонецЕсли;

        Если Пользователь.ПометкаУдаления
            Или НЕ Пользователь.Активен Тогда
            ВызватьИсключение "Пользователь удалён или неактивен.";
        КонецЕсли;

        Набор = РегистрыСведений.ПаролиПользователейПриложения
            .СоздатьНаборЗаписей();
        Набор.Отбор.Пользователь.Установить(СсылкаПользователя);
        Набор.Прочитать();

        // Начальная установка только один раз: никаких скрытых
        // перезаписей/сбросов чужого уже установленного пароля.
        Если Набор.Количество() <> 0 Тогда
            ВызватьИсключение "Для пользователя уже есть пароль.";
        КонецЕсли;

        ЗначениеПароля =
            ВычислитьСохраняемоеЗначениеПароляПользователя(Пароль);

        Если ТипЗнч(ЗначениеПароля) <> Тип("Строка")
            Или ПустаяСтрока(ЗначениеПароля)
            Или СтрДлина(ЗначениеПароля) > 1024 Тогда
            ВызватьИсключение "Некорректный результат хеширования.";
        КонецЕсли;

        Если НЕ ПроверитьСоответствиеПароляПользователяСохраняемомуЗначению(
            Пароль, ЗначениеПароля) Тогда
            ВызватьИсключение "Не удалось проверить созданный хеш.";
        КонецЕсли;

        Запись = Набор.Добавить();
        Запись.Пользователь = СсылкаПользователя;
        Запись.СохраняемоеЗначение = ЗначениеПароля;
        Набор.Записать();

        Проверка = РегистрыСведений.ПаролиПользователейПриложения
            .СоздатьНаборЗаписей();
        Проверка.Отбор.Пользователь.Установить(СсылкаПользователя);
        Проверка.Прочитать();

        Если Проверка.Количество() <> 1 Тогда
            ВызватьИсключение "Запись пароля не найдена.";
        КонецЕсли;

        Для Каждого СтрокаРегистра Из Проверка Цикл
            Если НЕ ПроверитьСоответствиеПароляПользователяСохраняемомуЗначению(
                Пароль, СтрокаРегистра.СохраняемоеЗначение) Тогда
                ВызватьИсключение "Сохранённый хеш не прошёл проверку.";
            КонецЕсли;
        КонецЦикла;

        ЗафиксироватьТранзакцию();
    Исключение
        ОтменитьТранзакцию();
        ВызватьИсключение "Установка начального пароля не выполнена.";
    КонецПопытки;

КонецПроцедуры
```

### Важные замечания

- Обычный запуск сохраняет первоначальный хеш **по-настоящему**:
  **не использовать на тестовом пользователе, если требуется откат**.
  Для проверки без следов уже есть
  `docs/password-register-diagnostic-85.md`.
- Код **не осуществляет повторную смену**: если запись уже есть,
  она не будет перезаписана.
- Значения для `НовыйПароль` и `ПовторПароля` вводятся
  исключительно в 1С и не отправляются через HTTP, чат, git или CLI.
  Не следует логировать тело, содержимое формы или временные
  переменные, содержащие пароль.
- Функция с директивой `&НаСервереБезКонтекста` исполняется
  на сервере 1С. Этот код не требует системного пользователя ИБ,
  но **также не имеет встроенной проверки полномочий оператора**.
- Не добавлять к форме веб-маршрут установки/сброса.
- Проверку синтаксиса и поведения нужно выполнить в той версии
  Конфигуратора, которой реально пользуется владелец базы.
  Этот репозиторный исходник не является скомпилированным `.epf`.

Переход паролей Django -> 1C по сети остаётся отдельной задачей
(нужен безопасный транспорт и авторизованный запрос; нельзя использовать
действующий анонимный HTTP :8081).
